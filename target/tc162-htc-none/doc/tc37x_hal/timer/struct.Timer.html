Struct tc37x_hal::timer::Timer

source · 
pub struct Timer { /* private fields */ }
Expand description

Implementations for the Cancel, CountDown and Periodic traits.

In the implementation tim0 register is used to read the system timer’s value.

Example

use tc37x-hal::Timer;
#[macro_use(block)]
extern crate nb;
let timer = Timer(50_000_000_u32);
// The following instructions will block for at least 0.1 sec.
timer.start(100_u32);
block!(timer.wait());

Example

use tc37x-hal::Timer;
let timer = Timer(50_000_000_u32);
timer.start(100_u32);
loop {
    if let Ok(_) = timer.wait() {
        //code here will run every 0.1s.
    }
}

impl Timer

pub fn restart(&mut self)

Restarts a cancelled timer

/// ### Example

use embedded_hal::timer::{Cancel, CountDown};
use tc37x-hal::timer::Timer;
let mut timer = Timer::new(50_000_000_u32);
timer.start(500_u32);
let mut is_running = true;
loop {
    if is_running {
        timer.cancel().ok();
    } else {
        timer.restart();
    }
}

source§

impl Periodic for Timer

The countdown is restarted when finished by a hardware interrupt and a flag in the memory is set. Setting this flag is truly periodic with a period of count set when Timer::start was called. Clearing this flag is not necessarily periodic, since clearing happens when Timer::wait is called and should return Ok (or upon Timer::start and Timer::cancel).
