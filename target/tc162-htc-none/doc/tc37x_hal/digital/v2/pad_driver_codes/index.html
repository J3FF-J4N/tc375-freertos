Module tc37x_hal::digital::v2::pad_driver_codes

source ·
Expand description

Module contains constants for configure GPIO line’s output driver strength and slew rate.

The constants defined here are used to configure pad driver mode for GPIO ports with the PDR0 and PDR1 registers. See section 16.4.3. of AURIX™ TC3xx Target Specification document.
