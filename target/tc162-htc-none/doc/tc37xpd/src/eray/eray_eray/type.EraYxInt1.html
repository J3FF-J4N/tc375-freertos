pub fn srpn(self) -> RegisterField<0, 0xff, 1, 0, u8, EraYxInt1_SPEC, RW>

Service Request Priority Number. The SRPN bit field defines the priority of a service request with respect to service requests with to the same service provider same SRC.TOS configuration 00 gt Service request is on lowest priority … FF gt Service request is on highest priority For a CPU 01 is the lowest priority as 00 is never serviced. For a DMA 00 triggers channel 0. For DMA SRPN must not be greater than the highest implemented DMA channel number.
