pub fn chrev(self) -> RegisterField<0, 0x3f, 1, 0, u8, Chipid_SPEC, R>

Chip Revision Number CHREV. This bit field indicates the revision number of the AurixPlus Platform device. The value of this bit field is defined in the product Data Sheet. Bits 3 0 are connected to the layer prog inputs 3 0 . Bits 3 0 are used to indicate the steps. These updates can be done with any metal fix or FW ROM change. Bits 5 4 are hard wired on top level. Bits 5 4 define the major silicon design steps A B C D … . These bits can be changed only with a major redesign.
