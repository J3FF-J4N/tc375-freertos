pub fn depth(self) -> RegisterField<28, 0xf, 1, 0, u8, Eifilt_SPEC, RW>

Digital Glitch Filter Depth DEPTH. DEPTH determines the number of port input samples considered in the calculation of the floating average digital filter output for all enabled FLRQ filters. A value of zero in this register disables all glitch filtering.
