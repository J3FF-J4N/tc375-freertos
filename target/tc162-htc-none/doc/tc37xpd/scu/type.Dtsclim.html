pub fn llu(self) -> RegisterField<15, 0x1, 1, 0, Llu, Dtsclim_SPEC, RW>

DTSC Lower Limit Underflow LLU. When this bit is set the related SMU DTSC alarm trigger is generated. This bit has to be written with zero in order to clear it. Writing a one has no effect. This bit is set when a DTSC measurement is finished and the result is below the lower limit i.e. DTSCLIM.LOWER .
