DTSC Bandgap Trim Value VBGTRIM. This bit field contains information about trimming of the DTSC bandgap.The Bandgap voltage is measured via Analog Test Bus at 125 176 C and the value is trimmed so that the measurement corresponds to 1.13V. DTSC Bandgap Signed Trim Value VBGPTRIM. This bit field allows device individual trimming of the bandgap trim value in production. The first bit is sign information. The range is 16 to 15.
