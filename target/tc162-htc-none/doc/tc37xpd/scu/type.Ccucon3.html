pub fn up(self) -> RegisterField<30, 0x1, 1, 0, Up, Ccucon3_SPEC, W>

Update Request UP. Setting this bit will request an update for CCUCON3 and CCUCON4. Only one UP bit must be set for either CCUCON3 or CCUCON4. This bit always reads as zero.

pub fn lck(self) -> RegisterField<31, 0x1, 1, 0, Lck, Ccucon3_SPEC, R>

Lock Status LCK. This bit indicates if the register can be updated with a new value or if the register is locked and a write action from the bus side has no effect. The lock bit is set when an update of CCUCON3 4 has been requested and released when the update is complete.
